# NXT DEX

Prototype decentralized exchange interface for NXT CLOUD.

- NXT PAD-inspired dark/cyan visual system
- Swap interface with local quote simulation
- Sui Testnet, Solana Devnet, Ethereum Sepolia selector
- Responsive static HTML/CSS/JavaScript

On-chain execution, routing, pools, and production wallet integrations are not enabled yet. Test assets have no value.
